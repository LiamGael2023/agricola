# 🌾 Agricola - Carrito de Compras de Productos Agrícolas

Una aplicación web moderna y responsiva para la venta de productos agrícolas.

## 🚀 Características

- ✨ Diseño moderno con las últimas tendencias
- 📱 Totalmente responsivo (móvil, tablet, desktop)
- 🎨 Paleta de colores agrícolas (verdes, tierra)
- 🛒 Carrito de compras funcional
- 💳 Interfaz intuitiva y fácil de usar
- ⚡ Rendimiento optimizado

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Variables CSS)
- JavaScript (Vanilla JS)

## 📦 Instalación

1. Clona el repositorio
2. Abre `index.html` en tu navegador

¡No se requiere instalación adicional!
