# 🌾 Agricola - Carrito de Compras de Productos Agrícolas

Una aplicación web moderna y responsiva para la venta de productos agrícolas frescos.

## 🚀 Características

- ✨ **Diseño Moderno** - Interfaz elegante con las últimas tendencias en diseño web
- 📱 **Totalmente Responsivo** - Optimizado para móvil, tablet y desktop
- 🎨 **Paleta Agrícola** - Colores verdes y tierra que evocan naturaleza
- 🛒 **Carrito Funcional** - Sistema completo de compras con persistencia
- 🔍 **Búsqueda Inteligente** - Encuentra productos fácilmente
- 🏷️ **Filtros por Categoría** - Organiza productos por tipo
- 🖼️ **Galería Interactiva** - Carrusel de imágenes con lightbox
- 🎭 **Hero Slideshow** - Banner animado con transiciones suaves (tamaño reducido)
- 💬 **Botones Flotantes** - WhatsApp y Facebook para contacto rápido
- 🔔 **Notificaciones** - Feedback visual para acciones del usuario
- 💾 **LocalStorage** - Carrito persistente entre sesiones

## 🎯 Funcionalidades Principales

### Hero Slideshow
- Banner reducido (250px de altura)
- 3 slides con transición automática
- Indicadores clicables
- Contenido dinámico por slide

### Categorías
- Carrusel horizontal con navegación
- 8 categorías: Vegetales, Frutas, Granos, Hierbas, Lácteos, Carnes, Orgánicos
- Iconos de Font Awesome
- Animaciones hover

### Productos
- 20 productos agrícolas variados
- Tarjetas con diseño moderno
- Información detallada (nombre, descripción, precio, unidad)
- Botón "Agregar al Carrito"
- Sistema de filtrado
- Búsqueda en tiempo real

### Carrito de Compras
- Sidebar deslizante
- Gestión de cantidades (+/-)
- Eliminar productos
- Cálculo automático del total
- Persistencia con localStorage
- Diseño intuitivo

### Galería
- Carrusel con 2 slides
- 4 imágenes por slide
- Lightbox para vista ampliada
- Navegación con teclado (flechas)
- Autoplay cada 5 segundos

### Características Adicionales
- Top bar con información de contacto
- Barra de búsqueda funcional
- Features/beneficios destacados
- Barra de contacto llamativa
- Footer completo con enlaces
- Botones flotantes de redes sociales
- Notificaciones de acciones

## 📱 Responsive Design

### Desktop (1200px+)
- Layout completo con todas las funcionalidades
- Navegación horizontal
- Carrito de 450px

### Tablet (768px - 1199px)
- Grid adaptativo de productos
- Menú hamburguesa
- Carrusel de galería en 2 columnas

### Móvil (< 768px)
- Layout vertical optimizado
- Carrito a pantalla completa
- Botones táctiles grandes
- Hero reducido a 200px
